# Mapa de Ajuste Elástico

Página para los alumnos del programa: el camino del módulo paso a paso, con el video al costado,
"¿cómo te fue?" en cada paso y un panel para Andy.

- `index.html`: la página publicada (se arma sola con `python3 construir.py`).
- `fuente/programa.js`: el contenido (pasos, consignas, opciones de progreso, videos). Es lo que más se edita.
- `servidor/Code.gs`: el código que va en Google Apps Script, pegado a la planilla donde se guarda todo.
